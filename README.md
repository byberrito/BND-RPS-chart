# BOYNEXTDOOR ship chart

A tiny fan-made page: tap a pairing, rate it (OTP / Like it / Don't really care / Hate it), then save your chart as a picture. Everything runs in the browser, with no server and no libraries. Your picks are stored only in your own browser.

## Customize it
Open `index.html` and edit the block between `EDIT THESE` and `END EDIT`:
- `MEMBERS`: the member names, in grid order.
- `PAIR_NAMES`: your own names for pairings, written like `"Sungho+Riwoo": "ship name"` (same order as `MEMBERS`).
- `RATINGS`: the choices, their labels and colors.

## Put it online (GitHub Pages)
1. Create a new repository on GitHub and upload `index.html` and this README.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
3. After a minute your page is live at `https://<your-username>.github.io/<repo-name>/`.
